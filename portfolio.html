Context

  • Researched and implemented spot VMs on the AWS clusters, with taints to control which workloads run on them.

Troubleshooting

I enjoy troubleshooting complex production issues. This is the order I work an incident in.

From alert to prevention

Scope
Infrastructure and application issues
Tools
Monitoring, logging, New Relic
Output
Root cause analysis
  1. Detect

    Monitoring and alerting catch the problem, ideally before users do: uptime checks, SLA dashboards, and notifications on critical endpoints.

  2. Diagnose

    Work from the symptom through the stack (DNS, load balancer, NGINX, certificates, the service and its host), using metrics and logs to rule layers out.

  3. Restore

    Get service back first, while keeping the evidence needed to find the cause.

  4. Prevent

    Write up the root cause and turn the fix into something durable: an alert, an automated check, or a script that removes the manual step.
